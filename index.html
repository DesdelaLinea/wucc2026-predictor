🔥 Conectar con Firebase
Pega los datos de tu proyecto Firebase para activar el leaderboard en tiempo real. Solo necesitas hacerlo una vez — se guarda en tu navegador.
¿Dónde consigo estos datos?
  1. Ve a console.firebase.google.com y crea un proyecto nuevo
  2. En el menú lateral: Firestore Database → Crear base de datos → Modo de prueba
  3. Vuelve a Project Overview → ⚙️ Configuración del proyecto → Tus apps → </> (Web)
  4. Registra la app y copia el bloque firebaseConfig que aparece
  5. Pega cada valor en los campos de abajo y haz clic en Guardar y conectar
