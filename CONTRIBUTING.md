# 🤝 Contribuir / Contributing

## Reportar un problema / Report a bug

Abre un issue en GitHub con:
- **Descripción:** ¿Qué ocurrió? / What happened?
- **Pasos para reproducir** / Steps to reproduce
- **Dispositivo y navegador** / Device & browser (ej. iPhone 15 / Safari 17)

## Problemas comunes / Common issues

| Problema | Solución |
|---|---|
| Spirit of the Game no aparece | Es la 4ta pestaña de cada división: Grupos → Fase intermedia → Championship → 🕊️ Spirit |
| Picks muestran 0 pts | Normal hasta que el admin ingrese resultados |
| No aparezco en el leaderboard | Verifica que hiciste clic en "☁️ Guardar en leaderboard" |
| El banner de sponsor no aparece | El admin debe activarlo en Admin → Campaña de Sponsor |
