## Reporting Issues / Reportar Problemas

If you find a bug or have a feature request, please open an issue on GitHub with:

Si encuentras un error o tienes una solicitud de función, abre un issue en GitHub con:

- **Description / Descripción:** What happened? / ¿Qué ocurrió?
- **Steps to reproduce / Pasos para reproducir:** How can we see it? / ¿Cómo podemos verlo?
- **Expected behavior / Comportamiento esperado:** What should happen? / ¿Qué debería pasar?
- **Device & browser / Dispositivo y navegador:** e.g. iPhone 14 / Safari 17

---

## Common Issues / Problemas Comunes

**The app doesn't save my picks**  
→ Make sure Firebase is connected (green dot in header) and you have entered your name.

**Los picks no se guardan**  
→ Asegúrate de que Firebase esté conectado (punto verde en el header) y que hayas ingresado tu nombre.

**My name appears twice on the leaderboard**  
→ Make sure you're using the exact same name each time (case-insensitive but must match).

**Mi nombre aparece dos veces en el leaderboard**  
→ Usa exactamente el mismo nombre cada vez (no importa mayúsculas pero debe coincidir).
